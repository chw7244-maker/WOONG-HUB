# WOONG HUB

취미와 일상을 기록하는 개인 대시보드. 「개인 HUB 제작 / 개인 대시보드 만들기」의 2026-11-17 설계와 하이브리드 디자인 선택을 기반으로 한 **0~1단계 개발 버전**입니다.

## 실행

Node.js 22.18 이상, pnpm 11.25.0을 사용합니다.

```powershell
pnpm install
pnpm dev
```

```powershell
pnpm check
node --test tests/store.test.mjs
pnpm build
node scripts/serve.mjs
```

빌드 결과는 `out/`입니다. 표준 Next.js App Router + React + TypeScript로 구현했으며 정적 호스팅이 가능합니다. Sites 프로젝트 ID는 `.openai/hosting.json`에 보존되어 있습니다. 현재 배포는 소유자 전용으로 유지합니다. 다른 호스팅에서는 별도 접근 제한을 구성해야 합니다.

## 구현 범위

- 반응형 홈, PC 사이드바, 모바일 하단 내비게이션
- 다크/라이트 테마, 홈 위젯 표시 설정
- 서울 기본값 및 도시 선택, Open-Meteo 날씨 조회와 실패/재시도 화면
- 한국 시간대 날짜, 월 이동 캘린더, 직접 일정 등록
- 할 일·메모·북마크·오디오·게임·앨범·업무 기록 추가/수정/삭제
- 통합 검색, 할 일 완료 처리, 일정 알림 목록
- 기기 내 JSON 저장, 다른 탭 동기화, 검증을 거친 JSON 가져오기/내보내기
- 기존 개인 뉴스, IEM Atlas, 스토어 인사이트 바로가기
- 모바일 설치용 웹 앱 매니페스트 (오프라인 실행과 푸시는 미구현)

## 저장과 연결 상태

현재 기록은 **브라우저 localStorage**에만 저장됩니다. 기기 간 동기화, Supabase 로그인/DB는 아직 연결되지 않았습니다. 브라우저 데이터 삭제 전 설정에서 JSON을 내보내주세요. 저장 실패를 UI에 표시하고, 잘못된 백업이나 위험한 URL은 거부합니다. 백업 가져오기는 현재 데이터를 교체하므로 별도 확인을 받습니다.

Sites의 소유자 전용 접근 제한과 앱 자체의 데이터 저장 방식은 별개입니다. 현재 앱에는 사용자 ID 기반 서버 DB가 없습니다.

Google Calendar OAuth, Steam 계정, 뉴스 기사 API, AI 요약, 예약 실행, 가격 알림은 연결되지 않았습니다. 테스트용 기사·날씨·보유 장비를 실제 개인 데이터처럼 생성하지 않습니다. 날씨는 브라우저에서 API에 직접 요청하며 네트워크 상황이나 제공자 제한에 따라 실패할 수 있습니다. 폰트 실패 시 시스템 한국어 글꼴로 대체됩니다.
