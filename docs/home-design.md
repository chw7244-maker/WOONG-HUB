# WOONG HUB 카드 디자인 기준

홈은 [저널 시안](https://www.figma.com/design/foV06siyOan3FkFQeuMnrI?node-id=2-342)을 따른다. 1440×900과 1920×1080 PC에서 주간 일정을 전체 너비로 펼치고 다음 일정과 오늘 할 일을 두 열에 배치한다. 기본형 아이폰 17의 402px 너비에서는 주간 일정, 다음 일정, 오늘 할 일을 세로로 배치한다. 주간 일정의 날짜 기준은 한국 시간 월요일부터 일요일까지다.

저널 색은 사이트 전체의 테마 토큰이다. `src/app/globals.css`의 `:root`(다크)와 `:root[data-theme=light]`(라이트)에서 정의하며, 라이트는 아이보리와 브라운, 다크는 어두운 브라운이다. 홈 전용 배치와 다음 일정 배경(`--journal-hero`)은 `src/components/home-journal.css`에서 관리한다. 상단 헤더, 로고, 기본 버튼 모양도 이 파일에 있으며 모든 페이지에 적용된다. 다음 일정에는 Figma 시안의 Adobe Firefly 사진을 사용한다. ‘오늘’과 시간·날짜 숫자에 쓰는 글꼴은 필요한 문자만 포함해 `public/journal/`에 보관하며 SIL Open Font License 원문을 함께 제공한다.

## 공통 카드

| 요소 | 적용 기준 |
| --- | --- |
| 배경과 색 | 테마 토큰 `--bg`, `--panel`, `--panel-soft`, `--border`, `--text`, `--muted`를 쓴다. 강조색 `--accent`는 제목 아이콘, 시간, 링크, 선택 상태에 쓰고, 옅은 배경은 `--accent-soft`를 쓴다. 기본 버튼은 `--accent-strong` 배경에 `--on-accent` 글자색이다. 새 스타일에 색상 값을 직접 쓰지 않는다. 분야를 구분하는 카테고리 색(보라·청록 등)만 예외다. |
| 카드 형태 | 얇은 테두리, 데스크톱 16px·모바일 14px 모서리를 기본으로 쓴다. 기본 글자 크기에서 안쪽 여백은 데스크톱 16px·모바일 12px다. |
| 글자와 숫자 | 현재 글꼴을 사용한다. 카드 제목은 17px, 주요 내용은 16px, 보조 정보는 13px를 기준으로 한다. 시간과 건수는 폭이 같은 숫자를 사용한다. 긴 한글은 단어 경계를 우선해 줄을 바꾼다. |
| 아이콘과 버튼 | 제목에는 18px Lucide 아이콘과 30px 색상 배경을 쓴다. 주요 카드 링크와 모바일 버튼은 최소 44px 높이를 확보한다. 링크와 버튼에는 키보드 포커스를 표시한다. |
| 상태 표시 | 일정 없음, 할 일 없음, 조회 중 상태는 본문 자리에 짧게 표시한다. 카드에서 다음에 할 수 있는 행동은 같은 위치의 링크로 안내한다. |

기본 여백과 카드 제목은 `src/components/home-priorities.css`의 `.hub-summary-card`와 `.hub-summary-heading`을 사용한다. 홈의 저널 변형은 모서리와 포인트 색을 별도로 지정한다. 새 카드에 적용할 때는 PC와 아이폰 17 기준 화면에서 두 테마의 긴 제목, 빈 목록, 키보드 포커스와 주요 동작을 확인한다.

홈의 관심 뉴스 첫 기사에는 `public/news-fallback.jpg`를 표시한다. Adobe Firefly에서 차콜 배경 위에 푸른 윤곽의 무광 종이를 겹친 4:3 삽화를 만들었다. 글자와 로고를 빼고 형태를 단순하게 잡아 48×36px에서도 알아볼 수 있게 했다. 기사 제목과 출처는 이미지 옆에 텍스트로 표시한다.
