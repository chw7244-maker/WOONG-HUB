# 데일리 브리핑 운영

WOONG HUB의 **뉴스 → 오늘의 브리핑**에서 게임과 오디오·음악 전문을 날짜별로 읽고 CSV로 내보냅니다. 날짜를 선택하면 바로 열리고, 날짜 입력 양옆의 화살표로 하루씩 옮길 수 있습니다. 홈에는 최신 발행일의 종류별 대표 항목이 들어갑니다.

## 배포와 예약

1. `0005_daily_briefings.sql`을 포함한 사이트 버전을 배포합니다. 사이트는 소유자 전용 접근 정책으로 운영합니다. 게시 경로는 Sites 서비스 접근으로 인증하며, 로그인한 방문자의 요청은 조회·다운로드 경로에서 처리합니다.
2. 현재 Site의 `get_site` 응답으로 서비스 접근 값을 얻습니다. 이 값은 Sites가 확인한 사이트에만 `OAI-Sites-Authorization` 헤더로 전달하고 자격 증명은 세션 메모리에 보관합니다.
3. 서비스 접근으로 `GET /api/briefings/publish?format=contract`를 호출해 배포된 작성 규격을 확인합니다. `GET /api/briefings/publish?date=YYYY-MM-DD`의 응답에서 해당 날짜의 발행 여부를 확인할 수 있습니다.
4. 실제 자료를 조사하고 종류별로 `PUT /api/briefings/publish`에 JSON을 전달합니다. 전체 본문은 필수 `markdown` 필드에 넣고, 홈과 CSV에 사용할 대표 소식을 `items`에 넣습니다. 게시 후 날짜·종류·전문을 다시 읽어 확인합니다.
5. Sites 예약 작업은 매일 오전 8시(Asia/Seoul)에 실행합니다. 배포된 작성 규격을 읽고 직접 확인한 자료로 해당 날짜의 미게시 호를 작성합니다. 출처 확인에 실패한 종류는 게시를 보류하고, 성공한 종류는 따로 저장합니다.

## 기존 채팅 브리핑 가져오기

챗 원문을 열어 발행일을 확인하고, 한 브리핑이 여러 메시지로 나뉘어 있다면 게시 순서대로 이어 붙입니다. 원문의 제목, 문단과 표를 `markdown`에 두고, 본문 내 직접 링크를 Markdown 링크로 바꿉니다. ChatGPT 전용 이미지와 내부 인용은 `chatUrl`로 제공되는 ‘원본 채팅 열기’에서 확인할 수 있습니다. 원본 채팅을 열 수 있는 계정으로 접근해야 합니다.

`chatUrl`이 있는 원문 가져오기는 같은 날짜·종류의 이전 요약본 또는 Sites 자체 발행본을 한 번 교체할 수 있습니다. 원문이 저장된 뒤 반복 게시를 요청하면 기존 원문이 반환됩니다. 이전 날짜에도 가져올 수 있습니다.

`node scripts/publish-briefings.mjs`는 숨겨진 표준 입력으로 `{ "token": "…", "drafts": […] }`를 받아 게시하고 저장된 전문과 입력을 비교합니다. 긴 보고서는 `--draft-file`에 브리핑 배열을 담은 로컬 JSON 파일을 지정하고 토큰만 표준 입력으로 전달할 수 있습니다. 빈 `drafts`는 읽기 전용 작성 규격 확인에 사용합니다. CSV의 `briefing_markdown`에는 각 호의 첫 행에만 전문이 들어갑니다.

현재 Sites 예약은 별도 ChatGPT 채팅을 직접 읽는 경로가 없으므로 그 채팅에서 나온 호는 위 절차로 가져옵니다.

## 편집 기준

- 게임은 PC·콘솔, 국내 게임사, 모바일, 확인된 할인·무료 배포, 향후 7일 일정을 대상으로 합니다. GTA VI, 사이버펑크, 위쳐, Football Manager의 의미 있는 업데이트를 우선합니다.
- 오디오·음악은 국내 판매처가 확인한 IEM·장비 입고·가격·청음 여부, 해외 하드웨어·펌웨어, 신보와 향후 7일 일정을 다룹니다. 판매 조건과 발표 날짜는 원문에 표시된 기준으로 써 주세요.
- 한국어로 한 줄 요약, 확인된 핵심 소식 최대 다섯 건, 주제별 기사, 향후 7일 일정표와 후속 확인 사항을 작성합니다. 각 소식에 날짜, 중요성, 출처를 표시합니다. 최근 24시간을 우선하고, 전날과 같은 내용은 의미 있는 후속 정보가 있을 때 다시 싣습니다.

발행 데이터는 `daily_briefings`에 저장합니다. 기존 `news_articles`와 계정별 스크랩은 RSS 기사 화면에서 관리하며, 편집 브리핑은 별도 아카이브와 CSV를 사용합니다.
