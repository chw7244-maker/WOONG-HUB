# WOONG HUB

일정과 할 일을 중심으로 하루를 확인하고, 작품·음악·게임·오디오 같은 취미 기록을 한곳에서 관리하는 개인 대시보드입니다. Notion·Google 캘린더, Spotify, Steam, 맨시티 경기 일정과 관심 뉴스를 함께 볼 수 있습니다.

- **운영 사이트:** [WOONG HUB](https://woong-personal-hub.woong22222.chatgpt.site/) (ChatGPT Sites, 소유자 전용)
- **기술:** Next.js App Router · React · TypeScript, Cloudflare Worker 형식의 API, Sites D1(SQLite) DB
- **개발 미리보기:** 운영 DB와 분리된 로컬 SQLite로 실행합니다. [개발](#개발) 참고

## 화면 구성

| 메뉴 | 주소 | 내용 |
| --- | --- | --- |
| 홈 | `/` | 오늘 날짜와 요약, 날씨, 이번 주 일정, 할 일, 이어서 하기·관심 뉴스·맨시티 다음 경기 |
| 일정 | `/calendar/` | 월간·날짜별 캘린더, HUB 일정 등록, Notion·Google 반영본, 담은 맨시티 경기 |
| 취미 | `/hobbies/` | 작품 보관함(`/watch/`), 축구(`/football/`), 음악(`/music/`), 게임(`/games/`), 오디오(`/audio/`) |
| 뉴스 | `/news/` | 관심 뉴스, 전체 최신, 스크랩 |
| 기록 | `/library/` | 메모, 할 일, 북마크 |
| 더보기 | `/work/`, `/settings/` | 업무 기록, 설정(연결 관리·테마·홈 위젯·백업) |

PC에서는 위쪽 가운데의 알약 모양 메뉴(홈·일정·취미·뉴스·기록·더보기)를 씁니다. 모바일에서는 화면 아래에 떠 있는 메뉴(홈·일정·취미·뉴스·더보기)를 쓰고, 기록은 ‘더보기’에서 엽니다. 어느 화면에서든 검색 버튼이나 `Ctrl+K` / `⌘K`로 통합 검색을 엽니다.

## 홈

홈은 매일 확인하는 일정과 할 일을 가장 크게 보여줍니다.

- **오늘 요약** — 맨 위에 오늘 날짜를 큰 숫자로 쓰고, 남은 할 일 개수와 다음 일정을 한 줄로 요약합니다. 예: “할 일 **3개**가 남았어요 · 다음 일정 **수요일 05:00 맨시티 vs Napoli**”
- **날씨** — 날짜 옆 카드에 현재 기온, 오늘 최고·최저, 곧 올 비 소식, 24시간 기온 곡선을 표시합니다. 카드를 누르면 강수 요약, 시간별 24시간 예보, 일별 7일 예보가 펼쳐집니다. 기본 지역은 수원이며, 예보 화면이나 설정에서 전국 41개 도시 중 하나를 고릅니다.
- **이번 주** — 한국 시간 기준 월요일부터 일요일까지 날짜마다 날씨(최고·최저 기온)와 일정을 표시합니다. 오늘 칸은 강조색, 다음 일정은 강조 테두리로 구분합니다. 하루에 일정이 4개 이상이면 ‘+N개 더’에서 캘린더로 이어집니다. PC에서는 날짜 칸의 ‘+’로 그날 일정을 추가합니다. 모바일에서는 날짜 줄에서 하루를 고르면 아래에 다음 일정과 그날의 일정 목록이 나타나고, ‘일정 추가’로 그 날짜의 일정을 만듭니다.
- **할 일** — 입력칸에 적고 Enter를 누르면 오늘 마감 할 일로 바로 저장됩니다. 기한이 지난 할 일과 오늘 마감 할 일을 최대 5개 보여주고, 둥근 체크 버튼으로 완료합니다. 나머지와 마감일 없는 할 일은 ‘전체 할 일’에서 확인합니다.
- **하단 카드** — 이어서 하기(보던 작품, Spotify 재생·최근 감상, Steam 최근 게임, 청음 조합), 관심 뉴스 3건, 맨시티 다음 경기를 카드로 나란히 둡니다(PC 3열, 태블릿 2열, 모바일 1열). 최근 기록과 즐겨찾는 곳은 켜 두면 그 아래 전체 너비로 표시합니다.
- **빠른 추가** — 홈 위쪽의 ‘+ 추가’에서 일정, 할 일, 메모를 고릅니다. 할 일의 마감일은 선택 사항입니다.
- **홈 맞춤 설정** — 날짜 옆 위젯 설정 버튼이나 **설정 → 홈 위젯**에서 날씨·캘린더·할 일·뉴스·이어서 하기 항목·맨시티 경기의 표시 여부와 하단 카드 순서를 바꿉니다. 이 설정은 계정 동기화와 백업에 포함됩니다.

PC(1440px)와 아이폰 17(402px) 기준 배치는 [홈 디자인 기준](docs/home-design.md)에 정리했습니다.

## 디자인

- **저널 톤:** 모든 화면은 라이트 테마에서 아이보리와 브라운, 다크 테마에서 따뜻한 브라운 계열을 씁니다. 테마는 **설정 → 화면과 테마**에서 바꿉니다. 모바일 상단 상태 표시줄 색도 테마를 따릅니다.
- **떠 있는 면:** 홈 카드는 테두리 대신 살짝 떠 있는 면으로 구분하고, 입력칸은 눌린 면으로 표시합니다. 다른 페이지의 카드는 아직 얇은 테두리를 씁니다.
- **글자:** 본문은 DM Sans와 Noto Sans KR, 날짜와 큰 숫자는 Bricolage Grotesque를 씁니다. 모든 화면에서 12px보다 작은 글자는 쓰지 않습니다. 글꼴을 불러오지 못하면 시스템 한국어 글꼴로 대체됩니다.
- **색 기준:** 색, 면, 글꼴은 `src/app/globals.css`의 테마 토큰(`--bg`, `--panel`, `--accent`, `--raise`, `--press`, `--display` 등)으로만 지정합니다. 헤더, 하단 메뉴, 홈 배치는 `src/components/home-journal.css`에 있습니다. 자세한 기준은 [홈 디자인 기준](docs/home-design.md)을 참고하세요.
- **저장 상태:** ‘서버 저장 완료’처럼 정상 상태는 숨기고, 저장 중이거나 오프라인·오류일 때만 화면 위에 표시합니다.

## 메뉴별 기능

### 일정

**Notion · Google 캘린더**

- 사용자가 고른 Notion 캘린더와 Google 캘린더를 원본 수정 없이 읽기 전용으로 반영합니다. 자동 작업은 만들지 않습니다. 사이트를 관리하는 ChatGPT 채팅에 ‘캘린더 일정 다시 반영해줘’라고 요청하면 갱신합니다. 운영 절차는 [캘린더 반영 문서](docs/calendar-update.md)에 있습니다.
- 월간 달력, 날짜별 일정, 종일·기간·시간 지정 일정, KST 표시와 원본 열기를 제공합니다. 직접 등록한 HUB 일정과 담은 맨시티 경기도 함께 표시합니다.
- 출처별 스위치와 모두 켜기·끄기로 표시할 캘린더를 고릅니다. 이 설정은 홈의 이번 주와 다음 일정에도 적용되며, 계정별로 동기화하고 백업에 포함합니다. 표시를 꺼도 반영본과 원본 일정은 삭제하지 않습니다.
- 외부 반영본의 마지막 반영 시각과 조회 기간을 표시하고, 기간 밖의 날짜에는 누락 가능성을 안내합니다. ‘반영 내역 새로고침’은 저장된 반영본을 다시 읽을 뿐, 제공자의 새 일정을 직접 조회하지 않습니다.
- 캘린더 자료는 소유자 전용 Site의 서버 반영본으로 보관합니다. 소스, 공개 GitHub, 빌드 산출물에는 실제 일정이나 출처 ID를 넣지 않습니다. 개인 HUB 백업은 표시 설정과 직접 등록한 일정만 포함합니다. Site를 공유하거나 공개하기 전에는 반영본의 접근 설계를 다시 확인해야 합니다.

### 취미

**작품 보관함 (영화 · 드라마 · 웹툰)**

1. **취미 → 작품 보관함 → 작품 추가**에서 영화·드라마·웹툰을 고르고 제목과 감상 상태(볼 예정·보는 중·완료)를 저장합니다.
2. 영화·드라마 카드의 **날짜 정하기**로 감상 예정일을 저장합니다. 웹툰은 작품 수정에서 연재 요일을 지정합니다.
3. **이번 주 볼 것**은 한국 시간 월요일부터 일요일까지 날짜별로 감상 예정 작품과 해당 요일의 웹툰을 보여줍니다. 완료한 작품은 목록에서 빠집니다.
4. 영화는 **감상 완료**, 드라마와 웹툰은 **다음 회차**로 진행도를 기록합니다. 회차를 올린 직후 **되돌리기**를 누르면 직전 회차와 상태가 복원됩니다. 드라마 시즌, 별점, 작품 링크, 감상 메모도 저장합니다.
5. 웹툰 카드의 **이 작품 소식 팔로우**를 켜면 관심 뉴스에 작품 소식이 반영됩니다. 작품 수정의 **관심 뉴스에 받을 소식**에서 연재 시작·연재 재개·휴재·완결을 각각 고릅니다.
6. 홈의 ‘이어서 하기’는 최근에 수정한 ‘보는 중’ 작품을 보여줍니다.

TMDB 검색(영화·드라마 제목, 포스터, 공개 연도 가져오기)은 운영 사이트의 선택 연동입니다. 설정 방법은 [배포 → TMDB 연동](#tmdb-연동)에 있습니다. TMDB 없이도 작품 직접 등록과 감상 기록은 모두 사용할 수 있습니다.

**축구 (맨시티 · EPL)**

- 홈과 **취미 → 축구 → 맨시티 일정**에서 맨시티 남자팀의 다음 경기와 예정 경기를 한국 시간으로 봅니다. 일정과 킥오프 시간은 [맨시티 공식 캘린더](https://www.mancity.com/calendars/mens)를 사용합니다.
- **내 일정에 담기**를 누르면 그 경기가 HUB 캘린더와 홈의 이번 주에 표시됩니다. 같은 경기는 한 번만 담을 수 있습니다. **일정 → 담은 맨시티 경기**에서 날짜로 이동하거나 담기를 취소합니다. 담은 경기는 동기화와 백업에 포함됩니다.
- 공식 캘린더에서 같은 경기의 킥오프 변경이나 취소가 확인되면 HUB에도 반영합니다. 취소된 경기는 다음 일정 후보에서 빠집니다.
- **EPL 순위표**(20팀, 맨시티 강조)와 **최근 EPL 결과**(맨시티 최근 리그 경기 최대 5건)는 [OpenLigaDB](https://www.openligadb.de/) 커뮤니티 집계이며, 화면에 조회 시각과 공식 사이트 링크를 함께 표시합니다.
- 서버는 축구 데이터를 15분간 최신으로 취급합니다. 이후 조회가 실패하면 마지막으로 조회한 정보를 ‘마지막 조회’ 시각과 함께 보여줍니다.

**음악**

- 앨범명·아티스트·포맷·상태와 직접 기록한 장르·발매일·별점(반점 단위)·최근 감상일·좋아하는 곡·태그·감상을 저장합니다.
- **MusicBrainz 검색:** 앨범명(선택적으로 아티스트)으로 앨범 그룹을 최대 8개 찾아 빈 정보만 채웁니다. 날짜는 최초 발매 정보라 직접 기록한 판본의 날짜와 다를 수 있습니다. 표지는 Cover Art Archive를 쓰고, 없으면 기본 음반 그림을 표시합니다.
- **Spotify 공유 링크:** Spotify의 **공유 → 링크 복사** 주소를 붙여넣고 ‘연결 정보 확인 → 적용 → 저장하기’를 누르면 공식 oEmbed로 공개 제목과 표지를 확인합니다. 빈 제목만 채우고, 추적값을 지운 앨범·플레이리스트 주소만 허용합니다. 상세 창에서 Spotify 재생기를 열 수 있으며, 재생기는 누를 때만 불러옵니다.
- **플레이리스트와 감상 기록:** 추가한 플레이리스트는 HUB 즐겨찾기에 등록되고 하트로 관리합니다(Spotify 계정의 보관함은 바꾸지 않음). 앨범·플레이리스트마다 날짜·곡·청음 장비·별점·최대 3,000자 메모로 감상을 남기며, 항목당 최대 200개까지 저장하고 검색합니다.
- **Spotify Premium 계정 연결:** 음악의 Spotify 관리 화면(`/music/spotify/`)이나 설정의 연결 관리에서 로그인합니다. 승인한 권한에 따라 재생 제어, 브라우저 재생, 라이브러리 조회, 플레이리스트 편집을 사용합니다. 자세한 내용은 [Spotify 연동 문서](docs/spotify.md)를 참고하세요.
- 검색·상태·포맷 필터와 등록순·앨범명순·아티스트순·별점순·감상일순 정렬을 제공합니다. 평균 별점은 직접 평가한 앨범만 포함하고, 0점과 미평가를 구분합니다.

**게임**

- 게임별 플랫폼·상태, 직접 기록한 플레이 시간, 별점(0~5점, 0.5점 단위), 시작일·완료일, 태그(최대 8개), 감상 메모를 저장합니다.
- **Steam 상점 정보:** 상점 URL이나 App ID를 넣으면 제목·제작사·배급사·장르·출시 표시·짧은 소개·커버를 미리 보고 빈 항목만 채웁니다. 공개 게임·DLC 정보만 사용하며 가격은 조회하지 않습니다. 공개 정보는 최대 24시간 캐시합니다.
- **Steam 계정 연결:** 게임의 Steam 연결 카드나 `/games/steam/`에서 Steam OpenID로 계정을 확인하고, 계정별 보유 게임·총 플레이 시간·최근 2주·최근 실행 정보를 조회합니다. 사용자 Web API 키를 사이트의 보안 입력창에 등록해야 합니다. 기존 수동 기록에 계정 시간을 따로 연결할 수 있습니다. 자세한 내용은 [Steam 연동 문서](docs/steam.md)를 참고하세요.
- 검색·플랫폼·상태 필터와 등록순·이름순·플레이 시간순·별점순 정렬을 제공합니다. 미입력과 0분·0점은 구분합니다.

**오디오**

- 장비 이름, 분류·상태, 제조사·모델, 구매일·구매가(원), 연결·출력, 소리 성향, 청음·사용 메모를 기록합니다.
- 청음 조합은 등록 장비 1~12개를 골라 연결 순서를 정합니다. 전기적 호환성은 자동으로 판단하지 않습니다. 장비를 삭제해도 조합은 남고, 빠진 장비는 ‘찾을 수 없는 장비’로 표시합니다.
- 보유 구매가 합계는 구매가를 입력한 보유 장비만 더하고, 가격을 입력한 장비 수를 함께 표시합니다.
- 제품 사양, 가격, 보유 장비를 외부에서 자동으로 만들지 않습니다. 새 컬렉션은 빈 상태로 시작합니다.

외부 정보 조회(TMDB, MusicBrainz, Spotify, Steam)는 로그인한 사용자만 쓸 수 있습니다. 서버는 정해진 주소로만 요청하고, 사용자 신원·쿠키·개인 기록은 외부 서비스나 공개 캐시로 보내지 않습니다. 조회에 실패해도 직접 입력한 기록은 그대로 유지합니다.

### 뉴스

**읽기**

- **관심 뉴스**가 기본 화면입니다. 기본 주제는 팔로우한 게임과 국내 게임 행사, 오디오, 음악, 영화·드라마, 웹툰, 맨시티·EPL, PC 하드웨어입니다. 분야와 기사 유형이 맞는 소식에는 추천 이유를 표시합니다.
- 최근 30일 기사를 기본으로 보여줍니다. 제목과 발행 시각이 가까운 보도는 한 카드로 묶고, 같은 소식의 공식 원문을 앞에 둡니다.
- **전체 최신**은 수집한 기사를 발행일순으로 보여주며 검색·분야·날짜·안 읽음 필터를 지원합니다. 적용 중인 조건은 분야 목록 아래에 표시되고, ×나 ‘조건 초기화’로 지웁니다.
- 기사 카드의 북마크 버튼으로 스크랩합니다. ‘기사 옵션’에서 읽음 상태 변경, 숨기기, ‘이 주제 덜 보기’, ‘이 출처 더 보기/덜 보기’를 고릅니다. 숨긴 기사는 **필터 → 숨긴 기사 보기**에서 되돌립니다. ‘스크랩 백업’은 저장한 기사 최신 1,000건을 JSON으로 내보냅니다.

**관심 설정**

- 새 주제와 한글·영문 별칭을 추가하고, 출시·패치나 연재·완결 같은 기사 유형을 고릅니다. 최대 20개 주제를 팔로우할 수 있습니다.
- 내 게임을 직접 추가하면 연결된 Steam App ID로 한국어 공식 공지를 받습니다(최대 8개).
- 보관함에서 팔로우한 웹툰은 기사 제목의 작품명과 소식 유형이 맞으면 **작품명 · 연재 상태**를 추천 이유로 표시하고, **작품 기록 보기**로 보관함 카드를 엽니다.
- **출처 선호**에서 출처별 선호를 바꾸거나 초기화한 뒤 ‘설정 저장’을 누릅니다. 선호는 관심 뉴스의 같은 날 기사 순서에 반영되고, 전체 최신은 발행일순 그대로입니다.

### 기록과 검색

- **기록**(`/library/`)에서 메모, 할 일, 북마크를 추가·수정·삭제합니다. 메모는 제목과 본문을 쓰고 ‘분류 및 링크’에서 추가 정보를 넣습니다. 모바일에서는 편집기가 전체 화면으로 열리고, 작성 중인 초안은 그 기기에 보관됩니다.
- **업무**(`/work/`)에서 업무 기록과 자주 쓰는 도구를 관리합니다.
- **통합 검색**은 제목·메모·분류, 음악 아티스트·태그·감상별 곡/장비/메모, 게임 태그·App ID, 장비 상세를 함께 찾습니다. 검색어가 여러 개면 모두 포함된 항목만 보여줍니다.
- 범위는 전체 / HUB 기록 / 영화·드라마·웹툰 / 음악 / 내 게임 기록 / Steam 보유 게임 중에서 고릅니다. 결과는 20개씩 더 봅니다. Steam은 연결한 모든 계정의 저장된 보유 목록에서 찾고, 같은 게임도 계정별로 구분합니다.

## 저장과 동기화

- 기록과 설정은 **Sites D1 DB의 사용자별 문서**에 저장합니다. ChatGPT 로그인을 그대로 쓰며 별도 계정이나 API 키는 필요하지 않습니다. API는 플랫폼이 넣어 주는 사용자 ID로만 문서를 읽고, 쓰기 요청은 같은 출처와 JSON 형식을 검사합니다.
- 15초 간격과 화면 복귀 시 동기화합니다. 저장할 때마다 문서 버전을 비교하고, 다른 기기의 변경이 먼저 저장됐으면 최신 문서와 세 방향으로 합칩니다. 같은 기록을 동시에 고치면 사본으로 남기고, 삭제와 수정이 겹치면 수정 내용을 보존합니다. 문서 크기는 사용자당 1MB로 제한합니다.
- 변경 내용은 먼저 계정·탭별 보류 기록으로 브라우저에 보관한 뒤 서버 저장을 확인합니다. 저장 중·오프라인 표시가 있을 때는 브라우저 데이터를 지우지 마세요. 다시 연결하면 남은 보류 기록을 재전송합니다. 완전한 오프라인 실행은 제공하지 않습니다.
- JSON 백업 내보내기는 아직 저장되지 않은 보류 변경도 포함합니다. 가져오기는 현재 기록을 교체하므로 확인 창을 거칩니다. 이전 `woong-hub:v1` 브라우저 기록이 있으면 ‘이전 기록 백업’과 ‘서버로 옮기기’를 표시하며, 원본은 지우지 않고 현재 기록과 합쳐 옮깁니다.
- 날씨는 서버에서 Open-Meteo를 먼저 조회하고, 실패하면 MET Norway를 씁니다. 서버 연결이 안 되면 브라우저가 Open-Meteo를 직접 조회합니다. Open-Meteo는 강수 확률을, MET Norway는 확률이 없을 때 시간별 예상 강수량(mm)을 표시합니다.

## 개발

Node.js 24 이상과 pnpm 11.25.0이 필요합니다.

```powershell
pnpm install
pnpm check      # TypeScript 검사
pnpm test       # 자동 테스트
pnpm build      # out/ 정적 화면 + dist/server/index.js Worker
pnpm preview    # http://127.0.0.1:3000
```

- 미리보기는 운영 DB와 분리된 `.sites-runtime/local.sqlite`(Git 제외)를 쓰고, 시작할 때 아직 적용하지 않은 SQL 마이그레이션만 적용합니다. `pnpm dev`도 같은 빌드 결과를 제공하므로, 코드를 바꾼 뒤에는 다시 빌드해야 합니다.
- 미리보기 서버가 넣는 사용자 ID `local-preview-owner`는 로컬 전용이며 배포 파일에 포함하지 않습니다.
- 빌드 스크립트(`scripts/build.mjs`)가 Next.js 정적 결과(`out/`)와 API(`worker/`)를 하나의 Cloudflare Worker 모듈 `dist/server/index.js`로 묶습니다. 정적 파일만 배포하면 API가 작동하지 않습니다.
- DB 스키마는 `db/schema.ts`, 생성된 마이그레이션은 `drizzle/`에 있습니다. 스키마를 바꾸면 `pnpm db:generate`로 새 SQL을 만들고 검토합니다. 사용자 데이터는 SQL 마이그레이션에 넣지 않습니다.

| 경로 | 내용 |
| --- | --- |
| `src/app/` | 페이지 라우트, 전역 스타일과 테마 토큰(`globals.css`) |
| `src/components/` | 화면 컴포넌트와 페이지별 CSS |
| `src/lib/` | 저장 형식, 동기화, 캘린더·날씨·뉴스 등 공용 로직 |
| `worker/` | API(`/api/*`)와 외부 서비스 연동 |
| `tests/` | `node --test` 자동 테스트 |
| `scripts/` | 빌드, 로컬 미리보기, 캘린더 반영, 배포 확인 스크립트 |

## 배포

- 운영 사이트는 ChatGPT Sites의 기존 프로젝트(`.openai/hosting.json`의 `project_id`)에 소유자 전용으로 배포합니다. `d1: "DB"`로 운영 DB를 연결하며, 운영 마이그레이션은 Sites 배포가 적용합니다.
- 배포는 ChatGPT의 Sites에서 진행합니다. GitHub `main`에 반영한 뒤 사이트 관리 채팅에서 최신 버전 배포를 요청합니다.
- `scripts/verify-deployment.mjs`는 배포된 사이트를 읽기 전용으로 점검합니다(DB 상태, 주요 경로, 로그인 없는 API 접근 차단). 사이트 주소와 서비스 토큰을 숨김 입력으로 받으며, 토큰은 출력하거나 저장하지 않습니다.

### TMDB 연동

1. [TMDB API 설정](https://www.themoviedb.org/settings/api)에서 API 사용을 신청하고 **API Read Access Token**을 복사합니다. ([TMDB 인증 안내](https://developer.themoviedb.org/docs/authentication-application))
2. [ChatGPT Sites](https://chatgpt.com/sites)에서 **WOONG HUB → ⋯ → 설정**을 열고, 환경 변수 및 시크릿에 `TMDB_READ_TOKEN`을 **시크릿**으로 추가합니다. ([Sites 설정 안내](https://learn.chatgpt.com/docs/sites/managing-a-site#configure-runtime-environment-values))
3. 시크릿을 저장한 뒤 사이트를 다시 배포합니다. ([시크릿 반영 안내](https://help.openai.com/en/articles/20001339-creating-and-using-chatgpt-sites))
4. **작품 추가 → 영화 또는 드라마 → 제목 입력 → TMDB 검색**에서 결과를 고르면 제목과 포스터·공개 연도를 가져옵니다.
