# 검증 기록

- TypeScript 정적 검사 통과
- Next.js 프로덕션 정적 빌드 통과 (홈 + 8개 메뉴 + 오류 경로)
- `node --test tests/store.test.mjs`: 5/5 통과
- 로컬 서버 HTTP 200 확인
- 브라우저 실제 날씨 응답 확인 (Open-Meteo, 서울)
- 할 일 등록 → 완료 → 새로고침 후 상태 유지 확인
- 저장 기록을 통합 검색에서 찾는 동작 확인
- 모바일 390×844 레이아웃과 하단 내비게이션 확인
- 캘린더 날짜 클릭 후 KST 오전 9시로 일정 입력 기본값이 설정됨을 확인

동작 확인용 할 일은 localhost 브라우저에만 저장되며 배포 소스와 프로덕션 데이터에는 포함되지 않습니다. 실제 아이폰 기기, 외부 서비스 계정 연동, 클라우드 DB와 오프라인 동작은 검증 대상에 포함되지 않습니다.
