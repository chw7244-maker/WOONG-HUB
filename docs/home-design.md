# WOONG HUB 카드 디자인 기준

홈은 [홈 재구성 시안 2](https://claude.ai/artifact/4EinW9jEKPy6py9HkT7AnB)를 따른다. 맨 위에 오늘 날짜를 디스플레이 숫자로 크게 쓰고, 남은 할 일과 다음 일정을 한 줄로 요약하며, 오른쪽에 날씨 카드를 둔다. 그 아래 PC(1440px)에서는 ‘이번 주’ 7일 칸과 할 일 카드를 나란히 놓는다. 1100px 이하와 아이폰 17(402px)에서는 세로로 쌓고, 모바일의 이번 주는 날짜 줄과 선택한 날의 일정 목록으로 바뀐다. 하단 위젯은 벤토 카드(PC 3열, 태블릿 2열, 모바일 1열)로 놓는다. 주간 일정의 날짜 기준은 한국 시간 월요일부터 일요일까지다.

저널 색은 사이트 전체의 테마 토큰이다. `src/app/globals.css`의 `:root`(다크)와 `:root[data-theme=light]`(라이트)에서 정의하며, 라이트는 아이보리와 브라운, 다크는 어두운 브라운이다. 떠 있는 면은 `--raise`, 눌린 입력칸은 `--press` 그림자 토큰을 쓰고, 큰 숫자는 `--display`(Bricolage Grotesque) 글꼴을 쓴다. 상단 헤더(알약 메뉴, 검색), 모바일의 떠 있는 하단 메뉴와 홈 배치는 `src/components/home-journal.css`에서 관리하며, 헤더와 하단 메뉴는 모든 페이지에 적용된다.

## 공통 카드

| 요소 | 적용 기준 |
| --- | --- |
| 배경과 색 | 테마 토큰 `--bg`, `--panel`, `--panel-soft`, `--border`, `--text`, `--muted`를 쓴다. 강조색 `--accent`는 제목 아이콘, 시간, 링크, 선택 상태에 쓰고, 옅은 배경은 `--accent-soft`를 쓴다. 기본 버튼은 `--accent-strong` 배경에 `--on-accent` 글자색이다. 새 스타일에 색상 값을 직접 쓰지 않는다. 분야를 구분하는 카테고리 색(보라·청록 등)만 예외다. |
| 카드 형태 | 홈 카드는 테두리 없이 `--panel` 면과 `--raise` 그림자를 쓰고, 모서리는 데스크톱 28px·모바일 24~26px다. 카드 안의 항목(날짜 칸, 할 일 줄)은 `--panel-soft` 면과 16~18px 모서리를 쓴다. 다른 페이지의 카드는 아직 얇은 테두리와 16px 모서리를 쓴다. |
| 글자와 숫자 | 현재 글꼴을 사용한다. 카드 제목은 17px, 주요 내용은 16px, 보조 정보는 13px를 기준으로 한다. 모든 화면에서 글자 크기는 12px보다 작게 쓰지 않는다. 배지, 건수, 캡션도 같다. 기본 `<small>`도 12px 아래로 내려가지 않는다. 시간과 건수는 폭이 같은 숫자를 사용한다. 긴 한글은 단어 경계를 우선해 줄을 바꾼다. |
| 아이콘과 버튼 | 제목에는 18px Lucide 아이콘과 30px 색상 배경을 쓴다. 주요 카드 링크와 모바일 버튼은 최소 44px 높이를 확보한다. 링크와 버튼에는 키보드 포커스를 표시한다. |
| 상태 표시 | 일정 없음, 할 일 없음, 조회 중 상태는 본문 자리에 짧게 표시한다. 카드에서 다음에 할 수 있는 행동은 같은 위치의 링크로 안내한다. |

기본 여백과 카드 제목은 `src/components/home-priorities.css`의 `.hub-summary-card`와 `.hub-summary-heading`을 사용한다. 홈의 저널 변형은 모서리와 포인트 색을 별도로 지정한다. 새 카드에 적용할 때는 PC와 아이폰 17 기준 화면에서 두 테마의 긴 제목, 빈 목록, 키보드 포커스와 주요 동작을 확인한다.

홈의 관심 뉴스 첫 기사에는 `public/news-fallback.jpg`를 표시한다. Adobe Firefly에서 차콜 배경 위에 푸른 윤곽의 무광 종이를 겹친 4:3 삽화를 만들었다. 글자와 로고를 빼고 형태를 단순하게 잡아 48×36px에서도 알아볼 수 있게 했다. 기사 제목과 출처는 이미지 옆에 텍스트로 표시한다.
