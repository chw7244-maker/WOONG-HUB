# 캘린더 수동 반영 운영 절차

사용자는 Notion Calendar의 노션 캘린더 4개와 구글 기본 일정·공휴일을 함께 표시하고, 자동 실행 없이 요청할 때만 반영하도록 선택했습니다. 캘린더별 표시 설정은 사용자 문서에 저장하며, 반영본을 교체해도 변경하지 않습니다.

## 접근 확인

1. `.openai/hosting.json`의 기존 project_id로 Sites `get_site`를 호출합니다. 현재 계정이 owner이고 허용 대상이 소유자 한 명뿐인지 확인합니다. 다른 사용자·그룹·외부 방문자가 있거나 공개 상태라면 수동 반영을 중단합니다. 접근 범위를 바꾸지 않습니다.
2. 서버의 `/api/calendar/sync`는 소유자 전용 Sites의 서비스 접근 경계 안에서 공통 캘린더 반영본만 다룹니다. 개인 HUB 문서를 쓰지 않습니다. `get_site`가 반환한 서비스 토큰은 그 Site의 `OAI-Sites-Authorization` 헤더로만 사용합니다. 토큰을 출력하거나 파일·Git·지시문에 저장하지 않습니다.
3. `sync-calendar.mjs`를 snapshot 없이 실행하면 기존 반영본의 출처·조회 기간·버전만 반환합니다. 아직 반영본이 없다면 사용자에게 대상 캘린더를 확인합니다. 새로운 출처를 임의로 추가하지 않습니다.

## 원본 조회

- Notion 플러그인의 `calendar_list_calendars`와 `calendar_list_events`를 사용합니다. 이 연결은 노션과 구글 제공자 일정을 함께 반환합니다. 기존 반영본의 승인된 source ID 목록과 provider만 사용하고 다른 출처는 제외합니다.
- 기본 조회 기간은 KST 기준 이번 달 1일부터 다다음 달 1일 직전까지입니다. 요청한 다른 기간이 있으면 따릅니다. Calendar 도구는 한 번에 한 달 이하만 조회하므로 28일 이하 구간으로 나눕니다. 처음·마지막 경계를 빠뜨리지 않고 겹친 이벤트는 source ID + event ID로 중복 제거합니다.
- 오류·누락·부분 응답이 있으면 이전 반영본을 지우거나 빈 결과로 교체하지 않습니다. 오류를 해결하거나 부분 범위를 명시해 사용자의 지시를 받습니다.
- DATE 기간은 start.date와 **종료일 미포함** end.date를 사용합니다. DATE_TIME은 시작·끝의 명시적 시간대 오프셋을 보존합니다. 반복 일정의 반환 인스턴스를 임의로 확장하지 않습니다.
- 제목·ID·출처 ID·기간·원본 webUrl만 반영합니다. 참석자·이메일·설명·회의 링크는 수집하지 않습니다. 구글 기본 일정의 이메일 이름 대신 `구글 기본 일정`을 표시 이름으로 사용할 수 있습니다.
- `CalendarSnapshot`은 `src/lib/calendar.ts`가 검증합니다. source provider는 notion 또는 google이고, 전체 자료는 1MB 및 4,000개 일정 제한 안에 있어야 합니다.

## 쓰기와 확인

1. `node scripts/sync-calendar.mjs`를 PTY로 시작합니다. 숨김 stdin 안내 후 JSON `{url,token,snapshot}`을 전송합니다. 큰 입력은 유니코드 글자를 쪼개지 않는 작은 조각으로 보내고 마지막에 줄바꿈을 넣습니다. source 자료도 Git에 저장하지 않습니다.
2. 스크립트는 기존 revision을 읽고 비교 후 원자적으로 교체합니다. 충돌은 다시 읽어 판단하며 무조건 덮어쓰지 않습니다. 재조회가 동일한 반영본인지 확인한 뒤 출처 수·일정 수·기간만 출력합니다.
3. 운영 캘린더와 홈에서 마지막 반영 시각, 출처별 개수, 종일·시간 일정을 확인합니다. 단순 데이터 반영에는 소스 수정·사이트 재배포가 필요하지 않습니다.
4. 사용자에게 반영 기간과 일정 수를 알립니다. 원본 일정은 수정하지 않습니다. 자동화나 예약 작업은 만들지 않습니다.

실제 출처 ID, 일정 내용, 서비스 토큰은 이 파일에 쓰지 않습니다. 운영 데이터는 Sites D1의 `notion_calendar_snapshots`에만 저장하고 로컬 확인은 무시된 `.sites-runtime/local.sqlite`를 사용합니다.
